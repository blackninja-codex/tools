# 🧠 Projects I Worked On

These projects were created to **practice coding**, **understand security concepts**, and **strengthen Python scripting** skills.

---

## 🧩 1. Code Practice
Goal: Improve logical thinking, algorithmic efficiency, and problem-solving.  
Examples:
- Implemented data structures (linked lists, stacks, trees) from scratch.  
- Built CLI tools for file operations and log parsing.  
- Automated repetitive tasks using Python scripts.  

---

## 🔒 2. Security Understanding
Goal: Deepen knowledge of cybersecurity principles and practical applications.  
Examples:
- Wrote scripts to detect weak configurations in local environments.  
- Analyzed HTTP headers, encryption mechanisms, and input validation.  
- Simulated attack/defense scenarios in isolated lab setups.  

---

## 🐍 3. Python Scripting Strengthening
Goal: Write clean, efficient, and secure Python code.  
Examples:
- Created utilities for log analysis and data extraction.  
- Used libraries like `requests`, `paramiko`, and `cryptography` for automation and secure communication.  
- Followed best practices: linting (flake8), typing (mypy), and packaging (setuptools).  

---

> ⚙️ Each project helped refine my ability to **think like a developer** and **analyze like a security engineer**, combining both worlds for practical, resilient solutions.
